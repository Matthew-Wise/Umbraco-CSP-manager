# Features

Reference documentation for CSP Manager's key features.

- [Nonce Tag Helper](nonce-tag-helper) — Add per-request nonces to inline scripts and styles without `'unsafe-inline'`
- [Configuration](configuration) — Configure CSP Manager behaviour via `appsettings.json`
- [Node Policies](node-policies) — Give a site, a section or a single page its own CSP policy, for all cultures or one, as a complete policy or as extra sources on top of what it inherits
